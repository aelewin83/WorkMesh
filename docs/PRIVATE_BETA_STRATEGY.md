# Private Beta Strategy

Relai's private beta is designed to answer whether people understand, trust, and return to a private network for secure hiring and trusted operational work.

## Early adopter priority

Prioritize communities that already coordinate sensitive or trusted work:

- Writing and Reporting
- Media and Production
- Research, Analysis, and Advisory
- Local Sourcing and Fixer Work
- Executive Assistance and Coordination
- Logistics and Transport

Security Coordination remains supported, but it should be introduced cautiously and framed as lawful coordination work, not tactical services.

## Success metrics

- Invite acceptance rate
- Signup completion
- Onboarding completion under three minutes
- First request created
- First application submitted
- First agreement created
- First secure thread opened
- First completed engagement
- Repeat engagement rate
- Return usage within seven days

## Rollout stages

1. Founder-seeded workflows with known contributors and employers.
2. Curated operational-focus cohorts where supply and demand are intentionally paired.
3. Limited invite expansion based on completed engagement quality, not raw referral volume.

## Trust-building priorities

- Explain protected settlement and secure messaging in plain language.
- Keep external references optional and disclosure-controlled.
- Use restrained seeded liquidity so the product feels alive without fake scale.
