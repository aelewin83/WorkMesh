# Trust And Abuse Risks

Trust in Relai comes from completed engagements, repeat collaboration, successful settlement, dispute-free history, and private endorsements.

Anti-patterns:

- Public follower counts.
- Public complete work history.
- Searchable collaboration graphs.
- Public invite chains.
- Moderator access to decrypted content by default.

Phase 3 introduces private trust summaries, private endorsements, encrypted reports, and hidden relationship weighting.
