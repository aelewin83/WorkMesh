# Incident Response Basics

## First Actions

1. Revoke affected sessions.
2. Rotate exposed secrets.
3. Disable suspicious admin accounts.
4. Review security events.
5. Preserve logs without exposing plaintext sensitive content.
6. Notify affected users with calm, specific guidance.

## User-Facing Guidance

- Revoke unknown devices.
- Rotate wallet/session credentials where relevant.
- Treat recovery packages as sensitive.
- Never share seed phrases or private keys.
