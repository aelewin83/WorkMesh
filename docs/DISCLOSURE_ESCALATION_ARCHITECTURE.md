# Disclosure Escalation Architecture

Relai separates team visibility from private contact disclosure.

Visibility modes control roster and collaboration context:

- `minimal`: default disclosure state for compartmentalized work.
- `operational`: limited role and participant context for team coordination.
- `expanded`: fuller context for trusted collaboration.

Private contact details, exact location, and external references remain governed by explicit user disclosure settings. Full Collaboration enables engagement-scoped messaging, not automatic contact sharing.
