# Engagement Structure Model

Relai uses engagement structures to make compensation feel professional without becoming payroll software.

## Canonical structures

- Flat Fee
- Hourly
- Day Rate
- Weekly/Retainer
- Negotiable/Open Proposal

## Product rule

Relai supports conversation, agreement, protected settlement, and completion. It does not implement surveillance time tracking, payroll administration, tax classification, or automated labor compliance.

## Agreement fields

- engagementStructure
- rateAmount
- rateCurrency
- estimatedDuration
- overtimeTerms placeholder
- paymentSchedule placeholder
- proposalNotes

## Matching

Matching may consider structure compatibility, but it should not create lowest-bid sorting or commodity rate shopping.
