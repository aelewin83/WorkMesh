# Relai Visibility Mode Model

Relai engagements default to `compartmentalized` visibility. Employers may choose a visibility mode per engagement:

- `compartmentalized`: contributors see the employer, their own assignment, and minimal room context. Contributor-to-contributor DMs are disabled.
- `operational_team`: contributors see a limited roster with aliases/handles and roles. DMs remain disabled.
- `full_collaboration`: contributors see a fuller engagement roster according to disclosure settings. Engagement-scoped contributor DMs are enabled.

Employers always retain full roster visibility for engagements they own. Visibility modes are engagement-scoped and do not create global directories or cross-engagement contributor networking.
