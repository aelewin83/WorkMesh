# Team Visibility Rules

Phase 3 visibility behavior:

- Employers can see the full roster, roles, and statuses for owned engagements.
- Contributors in Compartmentalized mode cannot enumerate the full contributor roster.
- Contributors in Operational Team mode can see limited handles/aliases and role labels.
- Contributors in Full Collaboration mode can see the engagement roster and use engagement-scoped contributor DMs.
- Removed or rejected contributors cannot access the room, roster, messages, or scoped DMs.
- No visibility mode exposes private contact information unless a user explicitly discloses it.

These rules are enforced server-side before room rosters or messages are returned.
